# ภารกิจโค้ดดิ้ง: เมืองข้อมูล

เกมเว็บสำหรับวิชา **วิทยาการคำนวณ** ผู้เรียนจัดลำดับคำสั่งให้หุ่นยนต์เดินเก็บข้อมูล หลบข้อผิดพลาด และไปถึงประตูส่งงาน

## จุดประสงค์การเรียนรู้

- อธิบายการทำงานของอัลกอริทึมแบบลำดับขั้นตอนได้
- ทดลองแก้ปัญหาด้วยคำสั่งเดินหน้าและเลี้ยวซ้าย/ขวา
- ใช้แนวคิดการทำซ้ำเพื่อลดจำนวนคำสั่ง
- ใช้การตรวจสอบก่อนตัดสินใจในสถานการณ์ที่มีข้อผิดพลาด

## วิธีใช้

1. เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์
2. เลือกคำสั่งจากกล่องคำสั่งด้านขวา
3. กด `เริ่มรัน` เพื่อดูหุ่นยนต์ทำงาน
4. ปรับลำดับคำสั่งจนผ่านภารกิจ

## การนำขึ้น Content Center

อัปโหลดไฟล์ `index.html` เป็นสื่อ HTML หรือบีบอัดทั้งโฟลเดอร์เป็น `.zip` แล้วนำขึ้นระบบตามรูปแบบที่โรงเรียนใช้งาน

## แนวทางจัดกิจกรรม

- ให้ผู้เรียนเล่นทีละด่านและอธิบายเหตุผลของลำดับคำสั่ง
- ให้จับคู่กัน โดยคนหนึ่งเป็นผู้ออกแบบอัลกอริทึม อีกคนตรวจหาข้อผิดพลาด
- หลังผ่านด่าน ให้ท้าทายผู้เรียนลดจำนวนคำสั่งให้สั้นลง
